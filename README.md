Tents is a logic puzzle game. The goal is to place tents in the grid so that every tree is paired with a tent according to grid constraints.

- Free and Open Source
- No Ads
- No Trackers or Telemetry
- No Data Collection
- Works Completely Offline

## How to Play

### Rules

1. Edge Numbers: The numbers along the top and left edges indicate the exact number of tents required in that column or row.
2. Pair with Trees: Each tent must be orthogonally adjacent (horizontally or vertically) to at least one tree. Every tree must connect to a tent.
3. No Touching Tents: Tents cannot touch each other in any direction, including diagonally.
